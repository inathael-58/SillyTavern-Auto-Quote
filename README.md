# Auto Quote — SillyTavern extension

ช่วยใส่เครื่องหมายคำพูด ตัวเอียง วงเล็บ ฯลฯ ให้ครบคู่และหันถูกทาง

- **เว้นวรรคสองครั้ง = ปิดให้** พิมพ์ `“สวัสดี` แล้วกดเว้นวรรคสองที กลายเป็น `“สวัสดี” ` ทันที
  - ใช้ได้กับทุกคู่ในรายการ: `“ ”` `‘ ’` `" "` `* *` `** **` `*** ***` `( )` `「 」` `『 』` `（ ）` `【 】` `《 》` `〈 〉` `« »` `[ ]` `~~ ~~` `` ` ` ``
  - ซ้อนกันได้ ปิดจากในออกนอก: `“ยิ้ม *โบกมือ` ␣␣ → `“ยิ้ม *โบกมือ* ` ␣␣ → `“ยิ้ม *โบกมือ*” `
  - ถ้าไม่มีอะไรเปิดค้าง เว้นวรรคสองทีก็เป็นเว้นวรรคสองทีตามปกติ
  - คีย์บอร์ด iPhone / Gboard ที่ตั้ง "เว้นวรรคสองครั้ง = จุด" ไว้ก็ใช้ได้ (จุดจะถูกแทนด้วยตัวปิด)
  - กด Ctrl+Z (หรือเขย่าเพื่อเลิกทำ) แล้วจะกลับเป็นช่องว่างสองช่องเหมือนเดิม
- **กลับทิศ “ ” ที่พิมพ์ผิดด้าน** — ฟอนต์หลายตัววาดสองตัวนี้แทบเหมือนกัน
  - หลังช่องว่างหรือต้นบรรทัด ต้องเป็นตัวเปิดเสมอ: พิมพ์ `”` ตรงนั้นจะกลายเป็น `“`
  - พิมพ์ `“` ต่อท้ายคำ ตอนที่มี `“` เปิดค้างอยู่ จะกลายเป็น `”`
  - `‘ ’` ก็เหมือนกัน (`’` ระหว่างตัวอักษร เช่น it’s ถือเป็น apostrophe ไม่แตะ)
- **แถบเครื่องหมายเหนือช่องพิมพ์** โผล่เฉพาะตอนเคอร์เซอร์อยู่ในช่องพิมพ์ แตะที่อื่นแล้วหายไป
  - ไม่ได้เลือกข้อความ: แตะเพื่อใส่ตัวเปิด (ถ้าต่อท้ายคำจะเว้นวรรคให้ก่อน)
  - **เลือกข้อความแล้วแตะ = ครอบ** ปุ่มจะเปลี่ยนเป็น `“…”` `*…*` ให้เห็น ครอบเสร็จข้อความยังถูกเลือกอยู่ แตะต่อได้เลย เช่น เลือก `สวัสดี` → แตะ `“` → `“สวัสดี”` → แตะ `*` → `*“สวัสดี”*`
  - แตะปุ่มเดิมซ้ำ = เอาออก · `*` บน `**ตัวหนา**` = `***ตัวหนาเอียง***`
  - เลือกหลายบรรทัด ครอบให้ทีละบรรทัด (Markdown ข้ามบรรทัดไม่ได้)
  - ปุ่ม `>` ใส่/เอาออก blockquote ทั้งบรรทัด
  - ปุ่มสีส้มขวาสุดคือตัวปิดของสิ่งที่เปิดค้างอยู่ แตะเพื่อปิด (แสดงเฉพาะตอนมีอะไรให้ปิด)
  - ปุ่ม ↶ ซ้ายสุด = **เลิกทำ** (และ ↷ ทำซ้ำ โผล่หลังกดเลิกทำ) สำหรับคีย์บอร์ดมือถือที่ไม่มีปุ่ม undo
    - เลิกทำทีละคำ (ตัดที่ช่องว่าง หรือหยุดพิมพ์เกิน 1 วินาที) · การปิด/ครอบที่ extension ทำให้นับเป็นหนึ่งขั้น
    - กดหลังส่งข้อความไปแล้ว จะได้ข้อความที่เพิ่งส่งกลับมาในช่องพิมพ์
- **แท็บตัวอย่างการแสดงผล** (Extensions → Auto Quote → ตัวอย่างการแสดงผล) ไว้เช็คธีมตอนเขียน CSS
  - ข้อความตัวอย่างที่มีครบทุกแบบ: หัวข้อ, *ตัวเอียง*, **ตัวหนา**, ***หนาเอียง***, __ขีดเส้นใต้__, ~~ขีดฆ่า~~, `โค้ด`, คำพูดทุกแบบ (" “ « 「 『), คำพูดซ้อนตัวเอียง/ตัวหนา, blockquote, รายการ, ตาราง, ลิงก์, เส้นคั่น, code block
  - แปลงด้วยตัวแปลง Markdown ตัวเดียวกับแชท (รวม regex ตอนแสดงผล) และใช้โครงสร้างข้อความแชทจริง (`.mes` › `.mes_block` › `.mes_text`) แก้ Custom CSS แล้วเห็นผลทันที
  - สลับดูแบบข้อความตัวละคร / ผู้ใช้ · แก้ข้อความตัวอย่างเองได้
  - **แสดงในแชท** ใส่ตัวอย่างชั่วคราวไว้ท้ายแชท สำหรับ CSS ที่เขียนแบบ `#chat .mes …` (ไม่บันทึกลงแชท หายเองตอนส่งข้อความ/เปลี่ยนแชท หรือกด "เอาตัวอย่างออก")
  - รายการสีจากธีม: ตัวแปร `--SmartTheme…` พร้อมค่าปัจจุบันและแถบสี แตะเพื่อคัดลอก `var(--…)`

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ตัวเลือก

| ตัวเลือก | ทำอะไร |
|---|---|
| เว้นวรรคสองครั้ง = ปิด | ปิดแล้วเว้นวรรคสองทีจะไม่ทำอะไร |
| เว้นวรรคหนึ่งช่องหลังปิด | `“สวัสดี” ` หรือ `“สวัสดี”` |
| กลับทิศ “ ” ‘ ’ ที่พิมพ์ผิดด้าน | ดูด้านบน |
| เปลี่ยน `"` ตรง ๆ เป็น `“ ”` | ค่าเริ่มต้นปิด |
| แถบเครื่องหมาย · ปุ่มปิด · ปุ่มเลิกทำ/ทำซ้ำ · เว้นวรรคก่อนตัวเปิด | เปิด/ปิดแต่ละอย่าง |
| ปุ่มบนแถบ | ตัวเปิดคั่นด้วยช่องว่าง เรียงตามที่พิมพ์ (ต้องมีอยู่ในรายการคู่) · `>` = blockquote |
| ใช้กับ | ช่องพิมพ์ข้อความเสมอ · ช่องแก้ไขข้อความในแชท (ค่าเริ่มต้นเปิด) · ช่องข้อความอื่น ๆ เช่นการ์ด lorebook (ค่าเริ่มต้นปิด) |
| คู่เครื่องหมาย | บรรทัดละคู่ `ตัวเปิด ตัวปิด` · ตัวเดียวถ้าเปิดปิดเหมือนกัน เช่น `**` |

## ไม่ทำงานที่ไหน

- **Custom CSS**, regex, Quick Reply script และช่องเขียนโค้ดอื่น ๆ (ไม่ว่าจะตั้งค่าอะไร)
- ช่องพิมพ์ข้อความ ตอนขึ้นต้นด้วย `/` (กำลังพิมพ์คำสั่ง)

## หมายเหตุ

- ตัวเปิดต้องติดกับข้อความ (`“สวัสดี` ไม่ใช่ `“ สวัสดี`) เลยไม่เข้าใจผิดกับ `:(` หรือ `2 * 3`
- ไม่จับคู่ข้ามย่อหน้า (บรรทัดว่าง) ตัวเปิดที่ค้างในย่อหน้าก่อนจะไม่ถูกปิดให้
- ตอนแตะแถบ คีย์บอร์ดและข้อความที่เลือกไว้ยังอยู่ ไม่หลุดโฟกัส
